# An Nhiên – Vương Quốc Toán Học V3.71
Google Account + Cloud Progress Sync.

1. Configure `firebase-config.js`.
2. Enable Google provider in Firebase Authentication.
3. Add your `*.github.io` domain to Authorized domains.
4. Create Firestore in Production mode.
5. Publish `firestore.rules`.
6. Deploy this folder with GitHub Pages / included GitHub Actions.

Progress remains cached in `localStorage` key `an_nhien_math_v2` and is synced to `users/{uid}/progress/main`.
See `HUONG_DAN_FIREBASE_CLOUD_SYNC_V3_71.md`.
